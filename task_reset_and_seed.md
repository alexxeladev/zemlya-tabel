# Задача — Сброс данных и создание тестовых (seed)

## Цель

Полностью очистить данные в dev-БД (кроме системного администратора) и создать свежий набор тестовых данных скриптом: 2 отдела, компании, графики, 6-8 сотрудников с разнообразными настройками для проверки граничных случаев. Табель часами НЕ заполнять — это сделают вручную.

Задача намеренно НЕ указывает имена конкретных функций, моделей, полей — разберись в коде сам. Действуй по правилу 3 попыток.

## ВАЖНО — безопасность

- Это операция на **dev-БД** (Postgres в Docker). НЕ на проде.
- Перед сбросом сделать бэкап:
  ```bash
  mkdir -p ~/backups
  docker exec -t $(docker ps -q -f ancestor=postgres:16) pg_dump -U tabel tabel > ~/backups/before_reset_$(date +%s).sql
  ```
- Системный администратор (is_system_admin=True) НЕ удаляется ни при каких условиях.

## Часть 1 — Скрипт сброса

Создай CLI-команду или скрипт (в стиле существующих CLI-команд проекта, например рядом с create-admin) для очистки данных:

- Удаляет все: timesheet entries, периоды, премии/KPI, удержания/займы, проценты распределения, сотрудников (кроме is_system_admin), отделы, компании, графики, производственные календари, audit log
- Порядок удаления — с учётом foreign keys (сначала зависимые, потом справочники)
- Системный администратор остаётся нетронутым
- Скрипт идемпотентный (можно запускать повторно)
- Выводит что удалено (количество строк по таблицам)

Назови команду понятно, например `reset-data` или `seed-reset`.

## Часть 2 — Seed-скрипт

Создай CLI-команду `seed-test-data` (или похоже) которая наполняет БД тестовыми данными.

### Компании (юрлица)

Создай 3 компании (из реальных в проекте):
- ЗемляМО (код zmo) — основная
- Комфорт (код kft)
- Секьюрити (код sec)

### Отделы

- ИТО
- Бухгалтерия

### Графики работы

- 5/2 (стандартный, hours_per_shift=8)
- 6/1 (если поддерживается, hours_per_shift=8) — опционально

### Производственный календарь

- Загрузить на текущий год (если есть механизм автозагрузки с xmlcalendar.ru — использовать его; если нет — пропустить, заполнится потом)

### Сотрудники (6-8, разнообразные)

Создай сотрудников покрывающих граничные случаи. Все пароли = `Test1234!`.

### Что НЕ создавать

- НЕ создавать timesheet entries (часы) — табель заполнят вручную
- НЕ создавать периоды — создадутся при работе с табелем
- НЕ создавать премии/удержания в данных — добавят вручную при тесте

## Acceptance criteria

1. Скрипт сброса удаляет все данные кроме системного админа, выводит статистику.
2. Seed создаёт 3 компании, 2 отдела, графики, ~8 сотрудников с разными настройками.
3. QA-учётки работают (можно войти каждой ролью, пароль Test1234!).
4. Сотрудники с граничными случаями присутствуют: фикс-ставка, коэф 0, без отдела, без графика, (заём если поддерживается).
5. Табель пустой (часов нет).
6. Скрипты идемпотентны (повторный запуск не ломается — либо чистит перед заливкой, либо проверяет существование).
