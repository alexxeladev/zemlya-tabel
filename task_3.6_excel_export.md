# Задача 3.6 — Экспорт табеля в Excel (форма Т-13)

## Контекст

Табель готов: ввод часов с разбивкой по компаниям, статусы периодов, расчёт ЗП, автозаполнение. Сейчас нужна **выгрузка в Excel** для передачи в бухгалтерию / 1С.

Формат — **классическая Т-13** с поправкой: каждый сотрудник представлен **N строками по числу компаний**, на которых он работал в этом периоде. В строке для компании — часы только этой компании по дням.

XML экспорт **в этой задаче не делаем** — вернёмся когда узнаем требования 1С.

Колонки (классические Т-13 + наша компания):

| № п/п | ФИО | Должность | Таб. № | Компания | Числа месяца (1-15) — 15 столбцов | Итого за половину месяца | Числа месяца (16-31) | Итого за половину месяца | Итого за месяц |
|---|---|---|---|---|---|---|---|---|---|
| 1 | Иванов Иван Иванович | Прораб | 0001 | ООО Альфа | 8 8 8 8 8 ... | 80 | 8 8 ... | 80 | 160 |
|   |                       |        |       | ООО Бета  | 4   4   ...   | 16 |          |  0 |  16 |
| 2 | Петров П.П. | Сметчик | 0002 | ООО Альфа | 8 8 ...      | 80 | 8 8 ...  | 80 | 160 |

Структура:
- Колонки до «Компания» (включительно) — фиксированной ширины, шапка с границами
- На каждый день в первой половине месяца (1-15) — узкая колонка с числом и днём недели в шапке
- После 15-го — суммарная колонка «Итого за 1-15»
- Дальше — дни 16-28/30/31
- После — «Итого за 16-конец»
- И финальная — «Итого за месяц»
- Праздничные дни в шапке — красный шрифт, выходные — серый
- ФИО, должность, табельный номер, № п/п объединены по строкам сотрудника (merge cells через rowspan = число его компаний)

#### 2. Эндпойнт

В `app/routers/timesheet.py` добавить:

```python
@router.get("/{year}/{month}/export/excel")
async def export_excel(
    year: int,
    month: int,
    department_id: int | None = None,
    actor: Employee = Depends(get_current_employee),
    db: Session = Depends(get_db),
):
    """Экспорт табеля в Excel формата Т-13."""
    # Права: admin, accountant, manager (своего отдела)
    if actor.role not in ("admin", "accountant", "manager"):
        raise HTTPException(403, "Доступ запрещён")
    
    excel_bytes = generate_t13_excel(db, actor, year, month, department_id)
    
    filename = f"timesheet_T13_{year}_{month:02d}.xlsx"
    return Response(
        content=excel_bytes,
        media_type="application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
        headers={
            "Content-Disposition": f'attachment; filename="{filename}"',
        },
    )
    # Audit log: action='timesheet_exported_excel', metadata={'year', 'month', 'department_id'}
```

## Подводные камни

- **openpyxl merged cells**: cell.value пишется в **верхнюю левую** ячейку merge-региона. Если попытаться записать в любую другую — значение игнорируется. Это важно для ФИО которое merged по строкам компаний.
- **Decimal vs float**: часы хранятся как Decimal в БД. При записи в openpyxl можно конвертировать в float (openpyxl нормально работает с float). Для целых значений можно `int()` чтобы не было «8.0».
- **Длинные ФИО**: ширина колонки 30 символов, но ФИО может быть длиннее. Использовать wrap_text=True в стиле или гарантировать что не обрезается.
- **Пустые ячейки vs ноль**: если на день/компанию нет entry, ячейка остаётся **пустой** (а не «0»). В Т-13 пустота = выходной или неявка.
- **Сотрудник без работы в периоде**: если у сотрудника НЕТ entries в этом месяце — он не попадает в выгрузку (нет смысла строки). Кроме случая «нет ни одного entry вообще» — тогда таблица пустая но шапка есть.
- **Производственный календарь не загружен**: подсветка просто не применяется, всё рабочее. Не падать.
