# Проверка изменений

1. Узнать, что гнать:

   ```bash
   python3 .claude/skills/check-changes/select_tests.py
   ```

   Скрипт смотрит `git diff HEAD` + неотслеживаемые файлы и печатает команды:
   тесты бэка, которые импортируют изменённые модули; `ruff` по изменённым файлам;
   `npm test && npm run build` при правке фронта; `alembic upgrade head` при новой
   миграции; PG-набор при правке протокола блокировок; предупреждение, если
   изменена только одна сторона пары-зеркала (`distribution.py` ↔ `distribution.ts` и т.п.).

2. Прогнать напечатанные команды. Бэкенд: 1–2 минуты на файл тестов; если файлов
   больше трёх — `run_in_background`. Полный `pytest` (~30 мин) — только в конце
   задачи и только в фоне.

3. **Подбор по импортам — нижняя граница, а не полный охват.** Проверку строить
   под ТРЕБОВАНИЕ задачи, а не под дифф (CLAUDE.md → «Правила работы»): выписать,
   каких мест касается требование, и добавить тесты/проверки для тех мест, которых
   дифф не коснулся, но требование касается. Экран — проверить глазами (скриншот
   через Playwright), ассерты этого не заменяют.

4. В отчёте пользователю: какие команды запускались и что они вернули; что НЕ
   проверялось — сказать прямо.
