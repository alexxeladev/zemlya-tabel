# Задача — Распределение по компаниям: умный дефолт по часам

## Контекст

В разделе «Расчёт ЗП» есть распределение «Итого начислено» по компаниям. Сейчас если процент распределения не задан вручную — система ставит 0% и ничего не распределяет. Это неверно.

**Нужно:** если процент НЕ задан вручную — распределять автоматически по фактическим часам сотрудника из табеля. Если процент задан вручную — считать по нему (ручной перекрывает автоматический).

Задача намеренно НЕ указывает имена конкретных функций, переменных, файлов. Разберись в коде сам. Действуй по правилу 3 попыток.

Перед началом — бэкап БД:
```bash
mkdir -p ~/backups
docker exec -t $(docker ps -q -f ancestor=postgres:16) pg_dump -U tabel tabel > ~/backups/before_distfix_$(date +%s).sql
```

## Логика распределения (новая)

Для каждого сотрудника в расчёте ЗП, при распределении «Итого начислено» по компаниям:

1. **Проверить — задано ли ручное распределение по %** (в карточке сотрудника или переопределение на месяц):
   - Если задано (проценты есть и сумма > 0) → распределять **по этим процентам** (как сейчас)

2. **Если ручное распределение НЕ задано** (пусто, все нули) → распределять **по фактическим часам** сотрудника из табеля за этот период:
   - Взять часы сотрудника по каждой компании из табеля
   - `доля_компании = часы_компании / всего_часов_сотрудника`
   - `сумма_компании = Итого_начислено × доля_компании`
   - Пример: Макеев 167ч ksec + 4ч rest = 171ч всего → ksec 97.66%, rest 2.34% → распределить Итого начислено по этим долям

3. **Граничные случаи:**
   - Если у сотрудника нет часов вообще (0) и нет процентов → вся сумма на основную компанию (default_company), либо показать предупреждение
   - Если только одна компания в часах → 100% на неё
   - Округление Decimal ROUND_HALF_EVEN, расхождение относить на основную/последнюю компанию

## Отображение

В таблице расчёта ЗП / ведомости:
- Колонки процентов по компаниям: если процент авто (по часам) — показать вычисленный процент, но визуально отметить что он **автоматический** (например серым цветом, или пометкой «авто», или плейсхолдером вместо заполненного значения)
- Если процент задан вручную — показать обычным цветом (как введённый)
- Чтобы пользователь видел: этот сотрудник распределён по часам автоматически, а вон тот — по ручному проценту

При вводе ручного процента в ячейку — он перекрывает авто, пересчёт по проценту. При очистке ячейки (обратно в пусто) — возврат к авто по часам.

## Что НЕ менять

- НЕ трогать расчёт самой зарплаты (оклад, переработка, премии, удержания) — только механизм РАСПРЕДЕЛЕНИЯ итога по компаниям
- НЕ трогать разбивку по часам в табеле (механизм отдельный)
- НЕ менять переработку (отдельный вопрос)
- Не рефакторить сверх задачи

## Acceptance criteria

1. Сотрудник БЕЗ ручных процентов, с часами на 2 компаниях (167 ksec + 4 rest) → Итого начислено распределяется 97.66% / 2.34% автоматически. Сумма по компаниям = Итого начислено.
2. Сотрудник С ручными процентами (Комфорт 50/ЗМО 30/ГХС 20) → считается по ним, часы игнорируются.
3. Очистка ручного процента → возврат к авто по часам.
4. Визуально различимо: авто-распределение vs ручное.
5. Сотрудник без часов и без процентов → не падает, сумма на основную компанию или предупреждение.
6. `pytest -v` зелёный, включая тесты: авто по часам, ручной перекрывает, очистка возвращает авто, граничные случаи.

## В конце
