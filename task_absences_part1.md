## Виды отсутствий (коды)

В ячейке дня табеля вместо часов можно поставить код отсутствия:

| Код | Значение | Оплата |
|---|---|---|
| ОТ | Отпуск оплачиваемый | оклад / норма_часов × (дни × 8) |
| ДО | Отпуск за свой счёт | не оплачивается (0) |
| Б | Больничный | 100%: оклад / норма_часов × (дни × 8) |
| Н | Неявка / прогул | не оплачивается (0) |

**ВАЖНО про больничный:** в этой части оплачиваем больничный БЕЗ годового лимита — просто по формуле 100%. Годовой лимит 10 дней (сверх — не оплачивается) будет добавлен отдельной задачей (Часть 2). Сейчас — все дни больничного оплачиваются 100%.

## Ввод в табель

В ячейке дня — сейчас вводятся часы (со слотами компаний). Нужно добавить возможность вместо часов поставить **код отсутствия**.

Механика (выбери что удобнее и чище в текущей вёрстке):
- В ячейке дня — переключатель/выбор: «часы» или «код отсутствия»
- Если выбран код — в ячейке отображается код (ОТ / ДО / Б / Н), часы для этого дня не вводятся
- Код на весь день (не по компаниям — отсутствие не привязано к юрлицу)
- Один день = либо часы работы (возможно по нескольким компаниям), либо один код отсутствия. Не одновременно.

Отображение: код должен быть визуально понятен (цветная метка, например ОТ — синий, Б — оранжевый, ДО — серый, Н — красный).

## Влияние на расчёт

### Норма и факт

- **Норма часов** — НЕ меняется от отсутствий (норма это плановые рабочие часы месяца по календарю)
- **Факт часов** — дни отсутствия НЕ считаются отработанными (в факт не идут)
- Появляется понятие «дни отсутствия» по типам — сколько дней ОТ, ДО, Б, Н

Уточнение по факту/норме для расчёта переработки: дни отсутствия исключаются из расчёта переработки (в день отпуска нет ни работы, ни переработки).

### Начисления

- **ОТ (отпуск)** — начисляется сумма: `оклад / норма_часов_месяца × (дни_отпуска × 8)`. Отдельная строка/колонка «Отпускные».
- **Б (больничный)** — начисляется: `оклад / норма_часов_месяца × (дни_больничного × 8)`. Отдельная строка/колонка «Больничный». (Пока без лимита.)
- **ДО, Н** — 0, не начисляется, просто отметка

### Влияние на оклад

Важный момент: если сотрудник часть месяца был в отпуске/на больничном — его **оклад за отработанные дни** должен считаться пропорционально (он не отработал полный месяц).

Логика: оклад начисляется за фактически отработанное время. Дни отпуска/больничного оплачиваются отдельно (отпускные/больничные), а НЕ окладом. То есть:
- `оклад_к_начислению = оклад_полный / норма_часов × отработанные_часы` (без дней отсутствия)
- `+ отпускные (за дни ОТ)`
- `+ больничные (за дни Б)`
- `итого начислено = оклад_к_начислению + отпускные + больничные + переработка + премии + KPI`

Проверь на примере: сотрудник оклад 50000, норма 167ч, был в отпуске 5 дней (40ч), отработал остальное. Оклад за отработанное + отпускные за 5 дней должны дать примерно полный оклад (плюс-минус, т.к. отпуск считается по 8ч/день).

## Acceptance criteria

1. В ячейке дня можно поставить код ОТ / ДО / Б / Н вместо часов.
2. Коды видны в табеле с цветовой меткой, есть легенда.
3. ОТ оплачивается: оклад/норма × (дни × 8), отдельной суммой.
4. Б оплачивается 100% по той же формуле (пока без лимита).
5. ДО и Н — не оплачиваются, только отметка.
6. Оклад за месяц с отсутствиями считается пропорционально отработанному + отпускные/больничные отдельно. На примере (5 дней отпуска) сумма осмысленна.
7. Дни отсутствия исключены из расчёта переработки.
8. Коды видны в Excel-выгрузке.
9. Роли: employee не видит финансов отсутствий (только свои коды), manager/accountant/admin видят.
10. `pytest -v` зелёный, тесты: оплата отпуска, оплата больничного, ДО/Н не оплачиваются, оклад пропорционально, переработка исключает дни отсутствия.

## Подводные камни

- **Взаимоисключение часы/код** — в один день либо часы, либо отсутствие. Не допускай оба одновременно (валидация).
- **Пропорциональный оклад** — самое сложное. Убедись что оклад + отпускные ≈ полный оклад когда человек в отпуске (не двойная оплата, не потеря).
- **Норма не меняется** — норма это плановые часы месяца, отсутствия её не уменьшают. Меняется только факт и появляются начисления за отсутствия.
- **Decimal** для всех денег.
- **Миграции** — alembic upgrade head + проверка.
- **Дни в часы** — отпуск/больничный считаем через дни × 8 часов (стандартная смена), как в формуле образца финдира.
