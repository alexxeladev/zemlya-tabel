# Задача — Переработка обратно на по-дневный расчёт

## Контекст

Расчёт переработки нужно вернуть с помесячного на **по-дневный** (ранее меняли на месячный по образцу финдира, теперь возвращаем к дневному — это финальное решение).

Задача намеренно НЕ указывает имена конкретных функций, переменных, файлов. Разберись в коде сам. Действуй по правилу 3 попыток.

Перед началом — бэкап БД:
```bash
mkdir -p ~/backups
docker exec -t $(docker ps -q -f ancestor=postgres:16) pg_dump -U tabel tabel > ~/backups/before_ot_daily_$(date +%s).sql
```

## Правильная логика переработки (по-дневная)

Для **каждого дня** периода отдельно:

1. Определить дневную норму сотрудника:
   - Обычный рабочий день = длительность смены по графику (`hours_per_shift`, обычно 8)
   - Сокращённый день (предпраздничный) = длительность смены − 1 (обычно 7)
   - Выходной/праздничный день — переработки НЕТ (эти часы идут в отдельную категорию «праздничные», по своим правилам)

2. Посчитать фактические часы сотрудника в этот день:
   - **Суммировать часы по ВСЕМ компаниям в этот день** (если 8ч на компании А + 4ч на компании Б = 12ч в день)

3. Если фактические часы дня > дневной нормы → переработка этого дня = разница
   - Недоработка (факт < норма) НЕ уходит в минус, переработка дня = max(0, факт − норма)

4. Переработка за месяц = **сумма переработок по всем дням**

## Отличие от текущего (месячного)

Сейчас скорее всего: `переработка = факт_за_месяц − месячная_норма`. Это НЕПРАВИЛЬНО, вернуть на суммирование по дням.

Пример разницы:
- Пн 10ч (норма 8) → +2, Вт 6ч (норма 8) → 0
- По дням: переработка = 2ч
- По месяцу было бы: (10+6) − (8+8) = 0ч
- Правильно = 2ч (по дням)

## Оплата переработки (не меняется)

Сумма переработки = `(оклад / месячная_норма_часов) × переработка_часов × коэффициент`
где коэффициент — из карточки (0 / 1 / 1.5). Меняется только КАК считаются часы переработки (по дням), формула оплаты та же.

## Что НЕ менять

- Формулу оплаты переработки (только способ подсчёта часов)
- Оплату праздничных/выходных (отдельная категория)
- Распределение по компаниям
- Другие части расчёта ЗП

## Acceptance criteria

1. Переработка считается по дням: сотрудник Пн 10ч + Вт 6ч (норма 8) → переработка 2ч (не 0).
2. Мультикомпания: 8ч компания А + 4ч компания Б в один день (норма 8) → переработка 4ч (сумма 12 > 8).
3. Выходные/праздничные часы НЕ попадают в переработку (отдельная категория).
4. Недоработка в день не уходит в минус.
5. Цифры в табеле и ведомости совпадают (единый расчёт).
6. `pytest -v` зелёный, тесты обновлены под по-дневную логику (кейсы: переработка в один день, недоработка в другой, мультикомпания в день, сокращённый день).

3. `pytest -v`
