# Задача — Фильтры в табеле как на странице «Расчёт ЗП»

## Контекст

На странице «Расчёт ЗП» фильтры полнее чем в табеле. Нужно привести шапку табеля к тому же виду.

Задача намеренно НЕ указывает имена конкретных функций, переменных, файлов. Разберись в коде сам (переиспользуй логику фильтров со страницы «Расчёт ЗП» — она уже работает там). Действуй по правилу 3 попыток.

## Что есть на «Расчёт ЗП» (эталон)

- Поиск: **«ФИО или таб.№»** — ищет и по ФИО, и по табельному номеру
- Фильтр **«Все компании»** — выпадающий список компаний
- Фильтр **«Все отделы»** — выпадающий список отделов

## Что сейчас в табеле

- Поиск: только по ФИО
- Фильтр отдела: есть
- Фильтр компании: НЕТ

## Что нужно сделать в табеле

1. **Расширить поиск** — искать не только по ФИО, но и по табельному номеру (как на «Расчёт ЗП»). Плейсхолдер поменять на «Поиск: ФИО или таб.№». По мере ввода фильтрует по совпадению в ФИО ИЛИ табельном номере (регистронезависимо).

2. **Добавить фильтр по компании** — выпадающий список «Все компании» + компании из справочника. При выборе компании — показывать только сотрудников/строки относящиеся к этой компании.
   - Уточнение по логике фильтра компании в табеле: сотрудник «относится к компании» если у него есть часы на этой компании в периоде, ИЛИ это его основная компания. Выбери консистентно с тем как это работает на «Расчёт ЗП» (переиспользуй ту же логику). Если на «Расчёт ЗП» фильтр по основной компании — так же в табеле.

3. **Фильтр отдела** — оставить как есть.

4. Порядок и вид элементов — как на «Расчёт ЗП»: поиск, компания, отдел (плюс существующие кнопки табеля «Заполнить по графику», «Excel» справа).

## Согласованность

- Фильтры должны работать **вместе** (поиск + компания + отдел одновременно сужают)
- Итоговые суммы при фильтрации — не вводить в заблуждение (как решали для поиска: либо по видимым, либо консистентно с текущим поведением)
- Переиспользовать существующую логику фильтров с «Расчёт ЗП», не изобретать заново

## ДОПОЛНИТЕЛЬНО — свернуть блок «ПО КОМПАНИЯМ» в подвале табеля

**Проблема:** блок «ПО КОМПАНИЯМ» внизу табеля разросся — при 8 компаниях занимает много места, большинство строк пустые (с прочерками, компании без часов).

**Решение:** сделать блок **сворачиваемым**, по умолчанию **скрыт**.
- Вместо всегда развёрнутого блока — заголовок-кнопка «ПО КОМПАНИЯМ ▸» (свёрнуто) / «ПО КОМПАНИЯМ ▾» (развёрнуто)
- По умолчанию свёрнут (скрыт)
- Клик по заголовку — раскрывает/сворачивает содержимое (строки компаний с часами и суммами)
- Состояние (свёрнут/развёрнут) можно запоминать в session state, но по умолчанию при заходе — свёрнут
- Когда развёрнут — показывает как сейчас (все компании или только с часами — оставь текущее содержимое, меняется только сворачивание)

## Что НЕ делать

- Не менять расчёты, не трогать другие части
- Не рефакторить сверх задачи

2. Появился фильтр по компании, работает.
3. Фильтр отдела работает как раньше.
4. Все три фильтра работают совместно.
5. Вид согласован со страницей «Расчёт ЗП».
6. Блок «ПО КОМПАНИЯМ» свёрнут по умолчанию, раскрывается по клику.
7. `pytest -v` зелёный (если есть тесты фильтрации).
